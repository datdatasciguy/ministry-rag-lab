Set up Ministry Search RAG

No terminal or Python installation needed. Your collection and answers stay on this computer.

1. Local model runtime

Keep Ollama running. Windows setup offers its official installer when it is missing. On Mac, install Ollama once from its official download page.

Get Ollama if needed

2. Your private collection

Choose the complete .sqlite search index supplied privately, or one you built from permitted source files. Book content is not included in this installer.

No collection selected.

This copies the index into your local app data. Allow space for a second copy. Previous collections are preserved.

3. Choose an answer model

Hardware figures are planning suggestions, not tested minimums. CPU inference can be slow. Tiny/mobile-scale models still run through this desktop app and have weaker answer reliability.

Only your chosen answer model and the index's embedding model are downloaded. Model downloads require internet access; inference uses the local runtime.

Open search

You can switch installed models inside search. Reopen this setup page after restarting the app to add a model. Closing the browser keeps the local app running; use Quit app on this page to stop it.
